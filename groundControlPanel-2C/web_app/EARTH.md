## 使用

### 转回视角时地形恢复（2026-09-24）

将 Cesium Globe 的地形瓦片缓存目标从默认 100 提高到 1000，并开启视野边缘相邻瓦片的低优先级预加载。近期看过的地形网格及关联资源更容易留在内存中，减少转回视角时重新加载、解码和上传造成的山体恢复过程。缓存数是软目标，不是内存字节上限；当前显示所需的瓦片可能超过该值。关闭数字地球仍销毁实例并释放资源。

真实 Cesium World Terrain 对照：相机位于 86.93°E、27.72°N、椭球高度 16000 m，俯仰 -0.32 rad，朝向从 0 转到 π 再回到 0，等待每个方向瓦片加载完成。默认设置原先显示的 108 块瓦片全部被释放，返回时调用地形加载 160 次；缓存 1000 加相邻预加载时原瓦片释放 0 块、返回加载调用 0 次。测试使用 NASA 底图以减少高分辨率影像加载干扰。这里统计的是地形 Provider 加载调用，不等于外网下载次数，浏览器 HTTP 缓存仍可能命中。

代价是更多内存、显存与相邻区域的下载；没有测量实际内存增量或帧率。首次查看新区域、超出缓存覆盖范围、按距离切换层级仍需加载，不能保证任意转动完全无细节变化。视野外不会持续加载整片高精度地形，本次未改动雾效、精度阈值和地形数据源。

应用源码后重新启动测试地球，复测仍为释放 0 块、返回加载 0 次；关闭后 Viewer 已销毁、画布为零。TypeScript、生产构建和构建新鲜度检查通过，正式 dist 已包含配置且不含测试探针。测试脚本为 `output/playwright/earth-terrain-cache-*.js`；隔离测试后台禁用 UDP，未重启用户地面站。

### 卫星影像来源（2026-09-24）

进入 **配置 → 卫星影像** 选择底图。预设包括 Esri World Imagery（默认，近景细节丰富）、EOX Sentinel-2 cloudless（2020 年合成，约 10 米，适合大范围观察）和 NASA Blue Marble（适合全球远景，近景细节有限）。EOX 公共服务限非商业用途并要求署名，具体条件见面板内的来源说明。

一次只启用一个在线卫星底图，远近视角都使用所选来源。更换来源可能减轻层级色差，但不能保证每个地区、层级均无拼接差异。真实地形仍由独立开关控制。

选择“自定义影像源”可填写 HTTP/HTTPS Web Mercator（EPSG:3857）XYZ 地址，例如 `https://example.com/tiles/{z}/{x}/{y}.jpg`；TMS 使用 `{-y}` 或 `{reverseY}`，可选 `{s}` 默认子域为 a/b/c；也支持 ArcGIS `/MapServer` 服务地址。填写最大层级及数据署名。服务须允许浏览器跨域访问，并提供第 0 层瓦片以完成连通检查。普通地图网页、WMTS capabilities 文件和任意 WMS 地址不能直接使用。

未启动时可保存选择，不加载 Cesium 或在线影像。运行时应用会先检查新服务，检查失败保留原影像与原选择；检查成功后替换，不改变相机、飞机或地形。此检查只验证服务初始化和一张根瓦片，不保证所有区域可用，后续瓦片失败另行提示。首次加载失败时使用本地备用底图。

设置保存在当前浏览器的 localStorage，刷新后保留，但仍须手动启动地球。更换浏览器、访问端口或清理站点数据后需要重新选择。自定义 URL 中若含密钥，也会保存在该浏览器中；Cesium 地形 Token 仍沿用独立的加密保存机制。

验证：87 项前端测试及 TypeScript/生产构建通过。独立浏览器实际加载三个预设源，并检查自定义 XYZ、无效地址、失败保留、刷新记忆、相机位置保持、未启动不请求影像，以及 720 px 窄窗口和关闭后画布释放。未测量帧率或全世界影像覆盖质量。

另以独立 Python 服务（8766，禁用 UDP）检查正式 dist：后台 WebSocket 在线，EOX 与自定义 ArcGIS MapServer 加载成功，关闭后画布释放，无页面脚本异常。HTTP 首页与 dist 一致，构建新鲜度检查通过；测试服务已关闭，未重启用户地面站。

### 拖动时影像跳变修复（2026-09-24）

移除相机开始/结束移动时主动降低/恢复瓦片精度的逻辑。原均衡模式会将
`maximumScreenSpaceError` 从 2 切到 4 再恢复为 2；影像不同层级可能采用不同照片，
造成远景大块变色、细节消失后又出现，即使关闭真实地形也会发生。
现在三档画质分别保持 3 / 2 / 1.5 的误差阈值，拖动不改变画布分辨率或精度标准。
真实相机距离变化仍会正常选择瓦片层级；原影像的拼接色差和新区域加载仍可能可见。
拖动时不再主动减少瓦片工作量，未测量这一调整的帧率影响。

独立 Edge 页面在包头附近关闭地形、固定相机、等待瓦片加载完成后复现旧行为：
仅触发移动开始事件，渲染瓦片从 56 块变成 29 块，结束事件恢复 56 块，并出现明显色差。
修复后三档画质的固定相机事件检查均保持瓦片集合不变；真实鼠标拖动在地形开启
（在线状态 ready）和关闭两种情况下均保持精度和画布尺寸稳定。关闭测试地球后画布为零。
71 项前端测试及 TypeScript/生产构建通过。浏览器辅助脚本及截图在
`output/playwright/earth-tile-*.js`、`output/playwright/earth-tiles-*.png`。

### 简化三维飞机（2026-09-23）

数字地球里的飞机改为本地 11 KB 固定翼 glTF 模型，包含立体机身、后掠机翼、尾翼和座舱。沿用每架飞机的颜色、断联灰色、编号、跟随与高度设置；模型随遥测航向转向。模型不读取俯仰和横滚，也不改变飞行控制数据。素材可由 `frontend/tools/build_aircraft_model.py` 重新生成。

前端 72 项测试与生产构建通过；在隔离的本地测试服务中用两架模拟遥测飞机检查了模型加载、0°/90° 航向和近景显示。测试结束后关闭了测试地球和服务。

### 白天静态天空（2026-09-18）

点击工具栏 **天空视角**，可直接进入能看见地平线的近地视角，并回到明亮的白天光照。
在 **配置 → 飞机与轨迹 → 跟随飞机** 选择单机后，左键拖动可围绕飞机观察；自由视角使用中键或 Ctrl + 左键拖动倾斜，滚轮缩放。
跟随初始距离约 2.8 km，镜头位于飞机上方约 450 m；仍可自行拉近、转动或返回全球视角。

**配置 → 白天天空** 提供默认开启的近地积云、高空薄云、远山薄雾、大气渐变四个独立开关。
新增云层没有风场或时间动画；镜头与飞机移动产生相对视差。全球云图及演示卫星仍使用原有动画开关。
云与薄雾是装饰效果，不代表实时天气；积云采用 Cesium 云图元近似体积外观，不是真正可穿入内部的体积云。
飞机使用简化的固定翼三维模型；遥测高度及统一显示高度的行为不变。

积云使用固定地理网格，在镜头附近按画质最多生成 81 / 169 / 225 个候选云团，空白格会跳过。
云底约在已加载地形上方 2300–4000 m；未加载地形时按椭球高度放置，后续利用已加载高程修正，不额外发起高程采样请求。
薄云为约 11 km 高的程序纹理云层。近地云在相机高度 18–83 km 之间淡出，远景由原全球云图接续。
隐藏页面不更新云格；新云层没有独立计时器，关闭地球时释放图元和监听。

兼容说明：启用透明混合，并在 `daylight.ts` 内给 Cesium 1.145 云集合补充绘制包围球，兼容不使用 OIT 的透明排序路径。
该版本逐个移除云时存在索引压缩问题，因此仅在地理格集合变化时使用 `removeAll()` 重建有上限的云组，保留噪声纹理。

### 基本操作

- 未点击启动：只有说明页面，不加载 Cesium、影像或地球数据监听。
- 启动后：远近视角均显示配置中所选的卫星影像，默认 Esri；在线影像尚未就绪时显示本地海陆地貌备用纹理。叠加国家、地区和主要城市地名，以及当前浏览器收到的飞机和轨迹。在线真实地形需要配置 Cesium ion Token，底图可独立使用。
- 切换页面：继续接收显示数据，保留实例和视角；导航旁的“运行中”标记会一直显示。
- 点击关闭：取消模块监听和待执行更新、销毁实例、释放图形资源。下次启动恢复上次视角。
- 刷新或关闭浏览器：不保存运行状态；重新打开后必须手动启动。
- 拖动旋转、滚轮缩放；Ctrl + 拖动倾斜视角。可定位全部飞机、跟随单机、开关轨迹。

在 **配置 → 飞机与轨迹 → 统一显示高度（米）** 中设置高度，输入后立即生效：留空或小于 0 时读取各机遥测 `alt`；`alt` 缺失、非数值、非有限值或小于 0 时使用 **2000 米**。填写 0 或正数时，所有飞机、实际轨迹及规划轨迹统一显示在该高度。切页及关闭后重新启动地球保留本次设置，刷新页面后恢复留空。
当前历史轨迹缓存只保留经纬度，因此自动模式下历史轨迹使用 2000 米；规划点没有高度时同样回退到 2000 米，不表示已恢复历史真实高度。高度数值直接用于 WGS84 参考椭球坐标，未进行海拔基准换算或地形跟随。
飞机模型只表示航向，不表现横滚、俯仰；大小是为了看清而设定的显示尺寸，不代表机体实际尺寸。没有有效位置时显示等待提示；断联后保留最后位置并标记过期。
彩色实线表示实际轨迹，蓝色虚线表示规划轨迹。地球只展示现有数据，不生成模拟飞行，也不发送飞行指令。

卫星影像需要联网，加载速度取决于网络和缓存。影像不可用时仍可在基础地球上显示飞机和轨迹。
左下角保留引擎和地图数据署名，点击 Data attribution 可查看来源；在线地形使用 Cesium ion 服务并保留数据署名。

## Token 导入与自动读取（2026-09-14，当前方式）

- 进入 Earth，点击右上角 **Token 设置**。可以粘贴自己的 Cesium ion Token 后点击“验证并保存”，或点击“从文件导入”，选择只包含 Token 的 UTF-8 文本文件。文件选择框中可输入完整文件路径。
- 导入时验证 Cesium World Terrain（asset 1）访问权限。成功后用 Windows DPAPI 按当前用户加密，原子写入 `%LOCALAPPDATA%\GroundControlPanel\cesium-token.dat`。读取 Token 内容后另行保存，不依赖原始文件路径；以后移动或删除导入文件不影响使用。
- 关闭进程、重启电脑或移动地面站目录后，仍从上述用户目录读取。换电脑或 Windows 用户需要重新导入。保存位置可以在 Token 设置中展开查看。
- 未导入、保存文件缺失或损坏时可继续使用普通地球；实际连接时发现 Token 失效或网络不可用，会回退并提示检查。文件存在只表示已保存，不保证云端权限始终有效。
- 提供替换和清除操作。错误 Token、验证超时或网络失败不会覆盖原 Token。成功导入或清除会更新正在运行的地形，不必重启软件。Token 更换后不需要重新构建前端。
- 只有首次保存时才创建用户文件；普通启动不创建文件、不访问 ion。打开 Token 设置只查询本机保存状态，手动启动地球并开启地形后才读取 Token 并连接 ion。
- Token 不再从 `VITE_CESIUM_ION_TOKEN` 或 `.env.local` 读取，也不写入源码、`dist`、地面站日志或 bootstrap。API 返回 Token 的响应禁止缓存，读写接口只接受本机访问及专用请求头，并复用原同源写入检查。
- 分发新源码或新 `dist` 时不要附带自己的原始 Token 文件；旧版构建若含固定 Token，也不要分发。浏览器直接连接 Cesium，仍可在请求中看到当前使用者自己的 Token。
- 当前加密保存实现支持 Windows，其他平台仍可运行普通地球。已有的地图、通信和飞行指令功能不依赖 Token。免费账户仍受 Cesium 套餐额度和使用条款限制。

本轮验证：63 项前端测试、70 项后端测试及 TypeScript/生产构建通过。浏览器实测未配置时普通地球、文件导入后的即时地形、清除后的回退、关闭地球画布释放。强制结束独立测试后台后，从另一个工作目录启动新进程，页面无需再次输入即可读取加密 Token 并加载地形。真实用户存储的读取与加密检查通过，新源码和构建产物不含本人的 Token。未重启实际地面站或进行飞行指令测试。

## 在线地形显示

- 地形默认开启，仅在手动启动数字地球后发起请求。配置面板提供“真实地形”开关和独立状态；点击“喜马拉雅”可查看倾斜山地视角。
- 连接初始化超过 20 秒、请求失败或地形瓦片报告错误时回退到光滑椭球。关闭再开启地形可重试。关闭数字地球后，迟到的请求结果不会重新启用地形。
- 飞机和轨迹高度现按上述配置规则显示；数值直接作为椭球高度，不是离地高度，高山区域可能与山体相交。没有增加高度基准换算、地形跟随或地形避障计算。

验证：Token 访问官方地形端点成功；58 项前端测试及 TypeScript/生产构建通过。在独立前端预览中实际看到喜马拉雅三维山体，验证了地形关闭/重开和关闭地球后画布为零。初始化失败、瓦片错误、超时及关闭后的迟到结果由单元测试覆盖。预览没有连接真实地面站后台，本次未验证真实飞机遥测高度或测量帧率。在线数据署名显示商用升级提示，正式商用需确认对应服务套餐。

## 与原地面站的关系

新增模块位于 `frontend/src/earth/`，页面位于 `frontend/src/views/EarthView.vue`。
除导航、懒加载路由和前端依赖/构建外，后台增加了独立的本机 Token 管理接口；协议、指令路由、原三个页面和二维地图逻辑未修改。

数据流是 `现有 Pinia 状态仓库 → EarthSession 只读适配 → 地球渲染器`。模块没有自己的 WebSocket。
历史轨迹复用当前浏览器的有界 TrackSession，保留序号缺口、清空 epoch 和每机容量限制；不从后端补取历史。
关闭地球不会清空地面站轨迹，重新打开会读取当时仍保留的轨迹。

Cesium 和它的 CSS 只由启动按钮动态导入。Worker、Assets 等随 `dist/cesium/` 本地部署。
不再设置固定帧率上限，绘制节奏跟随浏览器 requestAnimationFrame；120 Hz 屏幕可由浏览器提供更高刷新节奏，但不保证实际达到 120 FPS。
提供流畅、均衡、精细三档画质；没有变化时按需重绘。手势期间保持画布分辨率和瓦片精度标准稳定，不再在拖动开始/结束时切换精度。
像素比例和总像素预算在窗口尺寸或画质改变时调整，避免大窗口和高分屏叠加放大 GPU 负担。
现在可叠加 Cesium World Terrain 真实地形；没有接入三维建筑或实时阴影。
启动后即使切到其他页，仍会使用浏览器资源；关闭后引擎代码和部分共享缓存可能保留，但没有运行中的地球实例。

依赖固定为 Cesium 1.145.0。该版本共享地形索引缓存会保留已关闭 Viewer 的 GPU 缓冲区。
`cesiumCleanup.ts` 针对固定的 16×16 椭球地形网格，在 Viewer 销毁后仅清理该 context ID 的缓存，
同时显式销毁输入处理器、释放原生 WebGL 上下文。升级 Cesium 时必须重新验证此版本适配及反复启停的资源回收。
飞机 SVG 来自 Phosphor Icons，许可随源码和 `dist/licenses/` 一同提供。

## 持续更新内存优化（2026-09-08）

原先实际轨迹采用 Entity 静态几何批处理。分段虽然限制了应用侧修改范围，但 Cesium
仍会在段变化时重建整个颜色批次，并启用按 CPU 核心数扩展的几何 Worker 池。
之前的有限容量和启停检查没有覆盖持续高频更新期间的这项开销。

现改为低层 PolylineCollection：每架飞机的首段、完整历史、末段分别使用独立缓冲区，
日常增删点只更新两端的小缓冲区；历史仅在分段边界变化时调整。规划虚线也使用低层绘制。
保留全部轨迹容量、断线和清空语义，长距离连线按椭球弧线补点；未降低影像清晰度、帧率或像素比例。

独立 Edge 浏览器实测：24 核逻辑处理器，1440×1000 窗口，24 架飞机各保留 10000 点，
每秒 10 批持续更新（每批包含全部飞机），在线卫星影像。优化后运行约 5.5 分钟，期间进行四轮缩放、拖动和重新定位：

| 指标 | 修改前压力场景采样 | 修改后运行采样 | 关闭约 30 秒后 |
| --- | ---: | ---: | ---: |
| Worker 数 | 26 | 2 | 2（引擎共享池保留） |
| 页面渲染进程 Private Memory / MiB | 5137 | 338–425 | 193 |
| 页面渲染进程 Working Set / MiB | 5138 | 399–479 | 248 |
| GPU 进程 Private Memory / MiB | 424 | 557–756 | 300 |
| GPU 进程 Working Set / MiB | 150 | 286–381 | 154 |

这些是分时采样值，不是连续监测的峰值，也不是用户的 600→900 MB 场景复现或长时间无泄漏保证。
Windows 任务管理器的浏览器分组还包含浏览器主进程、其他标签页、扩展、网络与 GPU；
上表页面内存不能直接当成整个浏览器总量。影像和驱动缓存仍有波动，关闭也不保证立刻回到启动前数值。
没有为采样强制垃圾回收。关闭后画布和模块更新任务已移除；共享 Worker/已加载代码由引擎和浏览器保留。
