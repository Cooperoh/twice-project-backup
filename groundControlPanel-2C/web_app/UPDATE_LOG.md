# 更新记录

本文件只记录 `web_app` 每次具体更新了什么，并按日期倒序追加。当前版本的安装、运行、配置和
排查方法以 `README.md` 为准。

## 修改日期：2026-09-24

地形缓存补充：Cesium Globe 瓦片缓存目标从 100 提高到 1000，开启相邻瓦片预加载，减少转走再转回时重新恢复山体细节。真实在线地形固定位置转向对照中，原视野 108 块瓦片释放数从 108 降至 0，返回地形加载调用从 160 降至 0。此数不是外网请求数；内存和预加载流量会增加，缓存为软目标，不能保证所有新视野即时完成。具体测试范围见 EARTH.md。

数字地球新增“配置 → 卫星影像”，提供 Esri、EOX Sentinel-2 cloudless、NASA Blue Marble 和自定义 XYZ/TMS/ArcGIS MapServer 地址。只启用一个在线卫星底图，远近视角使用同一来源；设置保存在当前浏览器。未启动时仅保存选择，运行中检查新源后替换，检查失败保留原影像和配置；更换不影响相机、飞机或独立的地形设置。保留数据署名与来源使用条件说明。

移除相机移动开始/结束时主动降低/恢复瓦片精度的逻辑，减少拖动触发的影像层级跳变。仍保留 Cesium 根据距离选择层级的正常行为，不保证源影像完全无色差。

验证：87 项前端测试、TypeScript 和生产构建通过；独立浏览器实际加载三个预设源，验证自定义影像、失败保留、刷新记忆、未启动无影像请求、单一在线卫星图层、相机保持、窄窗口和关闭清理。未改动飞行指令和 UDP 路由。

## 修改日期：2026-09-14

数字地球改用首次导入、以后自动读取的 Cesium Token 配置。新增粘贴、文件导入、替换、清除和保存位置显示。
Token 验证成功后通过 Windows DPAPI 加密保存到当前用户 LocalAppData，脱离地面站目录；进程重启或工作目录改变不影响读取。
前端取消构建时固定 Token，改为运行时通过本机接口读取。无 Token 仍可启动普通地球，导入/清除实时更新地形；验证失败保留原配置。
新增接口限制本机请求，返回值禁止缓存，不将 Token 混入状态快照或通信审计。未改动飞行指令及 UDP 路由。
验证：前端 63 项、后端 70 项测试通过；TypeScript、生产构建和构建新鲜度检查通过。浏览器验证了文件导入、无 Token 普通地球、清除回退，以及强制结束独立测试进程后自动读取。检查新源码和 dist 不含个人 Token。

## 修改日期：2026-09-08

内存优化补充：Earth 实际轨迹和规划轨迹改用低层线条绘制。每架飞机分别保存首段、完整历史和末段的缓冲区，
避免每次新增点触发 Cesium 整批静态几何重建和大量几何 Worker。保留原轨迹点数、断线、清空和显示精度。
24 架、24 万点、10 Hz 模拟更新约 5.5 分钟，Worker 从 26 个降为 2 个；页面渲染进程私有内存采样约 338–425 MiB，
关闭后约 193 MiB，GPU 与影像缓存仍有独立占用。37 项单元测试、23 项浏览器回归通过（3 项按配置跳过），
生产构建和地球生命周期检查通过。测试口径、局限与本轮恢复步骤见 EARTH.md；未修改或重启真实地面站后台。

修改模块：frontend 新增 Earth 模块；导航、路由、依赖和构建接入；使用说明。

## 修改日期：2026-09-07

修改模块：backend/config.py、backend/state.py、backend/udp.py、backend/commands.py、config.toml、README.md、tests

1. UDP 发送直接按地面站现有无人机列表筛选目标。无人机进入列表后，即使显示断联仍继续发送；从未进入列表的无人机不发送。
2. 编队及指定 ID 的命令只发送给其中也在无人机列表里的成员；全局命令和急停发送给列表中的全部无人机。空发送范围明确报错，急停本地锁仍然生效。
3. 按用户澄清移除发送时的断联超时筛选、额外连接时间记录和发送线程断联复查，复用现有无人机列表；断联阈值仅影响状态显示。
4. 用逐机 `udp.targets = [{ id, host, port }, ...]` 替换共用 IP 和按位置分配的端口数组，支持不同 IP 使用相同端口、非连续 ID 和任意排列顺序。旧格式给出迁移错误，不再生成隐式的 24 个地址。
5. 按当前要求，主配置为 24 架无人机各自保留 `10.144.1.100` 与原对应控制端口，后续可逐行替换真实 IP。浏览器测试配置仍使用本机回环地址。
6. 发送审计记录每个实际目标的 ID、IP 和端口；提示文案改为向列表内目标发送。保留编队协议内容、队长顺序和不自动重发的规则。
7. 65 项后端测试通过，包括 24 个回环接收端仅列表内目标收包、不同 IP 相同端口、命令范围、列表内无人机断联后继续收到命令和配置校验。删除已不适用的断联后禁止发送测试。未进行真实无人机飞行或无线网络负载测试。

## 修改日期：8.10 号

修改模块：backend/audit.py、backend/instance.py、backend/udp.py、backend/app.py、run.py、stop_web_app.ps1、README.md、UPDATE_LOG.md、.gitignore、tests

1. 在 `web_app/audit` 中按每次后端启动时间创建独立的 `received-*.jsonl` 和 `sent-*.jsonl`，进程停止后自然停止记录。
2. 收包审计保存 UTC 毫秒时间戳、来源、字节数、解析状态和原始 UTF-8 文本；非法 UTF-8 或超长数据使用 Base64 保留原始字节。
3. 发包审计按实际目标端口保存 UTC 毫秒时间戳、交给 `sendto()` 的原始文本、字节数、返回值和错误。
4. 审计记录改由两个后台线程批量序列化和写盘，最多每 0.5 秒或每 256 条刷新；UDP 收发线程只做非阻塞入队，不等待磁盘。
5. 审计队列设置固定容量和丢弃诊断，磁盘异常或极端积压不会无限占用内存，也不会阻断收包、发令和急停。
6. 新增跨 Windows、Linux、macOS 的进程级文件锁，同一份 `web_app` 只允许一个后端实例；重复执行 `run.py` 会显示现有 PID 和地址，并按配置打开已有页面。
7. 新增带随机令牌的本机关闭接口；`stop_web_app.ps1` 优先请求后端排空审计队列并正常退出，无法正常关闭时才使用强制停止后备方案。
8. 明确浏览器页面和后端进程的生命周期相互独立：关闭标签页不会停止 UDP 通信或审计记录。
9. README 只保留当前版本的使用和工作原理，具体变更统一迁移到本更新记录，明确两份文档职责。
10. 根目录和 `web_app` 的 `.gitignore` 统一改为忽略其目录内的所有文件和文件夹，不再放行任何内容。
11. 后端测试补充原始收发审计、批量落盘、单实例锁、锁释放、运行身份和授权关闭验证，共 44 项测试通过。
